## 예제 노트북의 실행 환경

- 다음 환경에서 노트북 정상 실행을 확인했습니다.
    - 각자의 컴퓨터
        - Windows - CUDA 또는 CPU
        - Linux(WSL2 포함) - CUDA 또는 CPU
        - Mac(Apple Silicon)
            - 파이토치 2.2.2 이후는 인텔 CPU 맥을 지원하지 않습니다.
            - 일부 예제는 수정이 필요합니다. 맥OS 문서를 참고하세요.
    - 클라우드 환경
        - Google Colab
            - CPU 또는 GPU 런타임
            - TPU 런타임은 사용하지 마세요. 이 책의 코드는 일반적인 파이토치 방식으로 작성되어 있어 TPU에서는 매우 느리게 동작합니다. 자세한 내용은 구글 코랩 문서를 참고하세요.
- 표준 실행 UI는 Jupyter 확장을 설치한 VS Code입니다. 구글 코랩의 경우 코랩의 웹 UI가 여기에 해당됩니다.
    - 주피터 노트북을 실행할 수 있는 다른 IDE 또는 JupyterLab 등 웹 기반 환경도 가능합니다. 다만, 테스트는 해 보지 않았습니다.

## 게시된 노트북 출력 셀의 생성 환경

- 각 노트북에 함께 저장된 출력 결과는 저자의 작업 PC에서 생성한 결과로, 다음과 같습니다.
    - **OS**: Linux (Windows 11 + WSL2)
    - **GPU**: NVIDIA RTX 4070S(CUDA 13.2)
    - **Python**: 3.14
    - **PyTorch**: 2.12 (`cu132` wheel)
- 단, 동일한 환경이라도 결괏값은 달라질 수 있습니다. 다만 본문의 설명과 불일치는 발생하지 않습니다.
- 본문 수록 예제에서 CPU 이외의 하드웨어 가속기 장치가 반드시 필요한 코드는 없습니다.
    - 다만 GPU를 비롯한 하드웨어 가속기 장치를 사용하면 실습에 소요되는 시간을 줄일 수 있으므로 사용을 권장합니다.

    - 나머지: 출처(제목, 저자, 저장소 링크)와 라이선스 링크를 표시하고, 수정한 경우 그 사실을 밝혀야 합니다.
