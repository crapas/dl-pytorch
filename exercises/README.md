# 연습문제 풀이

이 디렉터리에는 『멀티모달까지 직접 구현하는 딥러닝 with 파이토치』의 연습문제 풀이 노트북이 올라갑니다.

## 공개 안내

**연습문제 풀이 콘텐츠는 2026년 10월 19일부터 순차적으로 공개할 예정입니다.**

1장부터 차례대로 공개하며, 풀이 노트북만 따로 올리지 않고 **동영상 해설, 블로그 글과 함께** 제공합니다. 문제를 푸는 과정과 그렇게 푼 이유를 함께 전하는 편이 도움이 된다고 보았기 때문입니다.

공개된 자료는 이 디렉터리에 장별로 쌓입니다. 파일 이름은 본문 예제 노트북과 같은 규칙을 따릅니다.

```
exercises/
├── ch01/
│   ├── 01-01_exercise.ipynb
│   └── ...
└── ch02/ ... ch13/
```

## 그동안 활용할 수 있는 것

풀이가 아직 공개되지 않은 장이라도 다음 자료가 도움이 됩니다.

- **절별 예제 노트북** — [`code_examples/`](../code_examples/)에 있습니다. 일부 연습문제는 예제 노트북의 코드를 그대로 사용합니다.
- **본문의 학습노트** — 각 장 끝에 요점 정리와 더 찾아볼 거리가 정리되어 있습니다.
- **추가 학습 자료** — [`articles/`](../articles/)의 프롤로그와 수학 노트가 막히는 자리를 풀어 줍니다.
