# 연습문제 풀이
이 디렉터리에는 『멀티모달까지 직접 구현하는 딥러닝 with 파이토치』의 연습문제 풀이 노트북이 올라갑니다.

## 공개 방식
- **풀이 노트북**은 매주 월요일에 그 주에 다룰 분량을 한꺼번에 올립니다. 아래 표의 링크로 바로 볼 수 있습니다.
- **해설 동영상**은 월요일부터 금요일까지 매일 오후 6시에 한 편씩 공개됩니다. 이번 주에 올라가는 동영상은 링크 옆에 업로드 시각을 적어 두었습니다.
    - 업로드 시각 이전에는 동영상 링크가 열리지 않습니다.
- 이 일정은 저자의 사정에 따라 변경 또는 연기될 수 있습니다.
- 순차 공개 일정과 무관하게 특정 문제에 대한 문의사항은 [깃허브 디스커션즈](https://github.com/crapas/dl-pytorch/discussions)에 질문 남겨주세요.
