# 예제 모델 찾아보기

- <직접 구현하는 딥러닝 with 파이토치> 본문에서 번호를 붙여 다루는 18개 예제 모델의 색인표
- 한 모델을 여러 절에서 다루는 경우 절마다 행을 나누고, 그 절에서 **어떻게 구현했는지**를 함께 적음
  - 예를 들어 모델 14는 11-1절에서 변분 오토인코더로, 11-2절에서 DCGAN으로 구현함
- 절별 예제 노트북은 깃허브 저장소의 `notebooks/` 디렉터리에서 확인할 수 있음
- 본문에 등장하는 클래스, 함수, 메서드 색인은 [파이토치 API 찾아보기](../api-index/README.md)에 수록

---

## 1부 파이토치로 딥러닝 시작하기

| 모델 | 이름 | 절 | 그 절에서 다루는 내용 |
|---|---|---|---|
| **1** | 외계 행성의 물리 법칙 검증 모델 | 1-3 | 낙하시간과 낙하거리 관측값으로 `y = ax² + b`의 두 파라미터를 찾는 회귀 분석 모델. 텐서와 자동 미분만으로 경사하강법을 직접 구현한다 |
| **2** | AND 게이트 시뮬레이터 모델 | 2-2 | 퍼셉트론을 텐서와 자동 미분으로 직접 구현한다. 손실 함수와 파라미터 갱신도 손수 작성한다 |
| | | 2-3 | 같은 모델을 `nn.Module`, 손실 함수 클래스, 옵티마이저 클래스를 사용하는 파이토치 고수준 API로 다시 만든다 |
| **3** | XOR 시뮬레이터 모델 | 3-2 | 단층 퍼셉트론으로 풀 수 없는 XOR 문제를, 은닉층을 더한 다층 퍼셉트론으로 구현한다 |
| **4** | 회오리 모양으로 분포한 데이터 분류 모델 | 3-3 | 세 클래스 다중 분류를 다층 퍼셉트론으로 구현한다. 활성화 함수와 손실 함수의 선택을 비교한다 |
| | | 4-2 | 같은 데이터를 `Dataset`과 `DataLoader`로 감싸 파이토치의 표준 데이터 파이프라인으로 학습한다 |
| **5** | MNIST 숫자 분류기 | 4-3 | 공개 이미지 데이터셋을 내려받아 다층 퍼셉트론으로 손글씨 숫자를 분류한다 |
| | | 5-2 | 같은 문제를 합성곱 신경망으로 다시 만들어, 이미지에 맞는 구조가 주는 차이를 확인한다 |

## 2부 구조에 숨은 특징과 의미

| 모델 | 이름 | 절 | 그 절에서 다루는 내용 |
|---|---|---|---|
| **6** | CIFAR-10 이미지 분류기 | 5-3 | 32x32 컬러 이미지 10종을 분류한다. 데이터 증강과 드롭아웃으로 과적합을 다룬다 |
| **7** | 작은별 변주기 | 6-2 | <반짝반짝 작은별>의 멜로디를 학습해, 마중물 멜로디 뒤에 이어지는 멜로디를 생성하는 순환 신경망 모델 |
| **8** | 오즈의 띄어쓰기 | 6-3 | 띄어쓰기가 없는 영어 문자열에 띄어쓰기를 넣는다. 순서를 기준으로 판단하는 LSTM 모델 |
| **9** | 오즈의 소설가 | 7-2 | <오즈의 마법사>를 학습해 문장을 이어 쓰는 생성 모델. 임베딩 계층과 LSTM으로 구현한다 |
| | | 10-3 | 같은 문제를 디코더만 사용하는 트랜스포머로 다시 만든다. 탐욕 디코딩, 온도 샘플링, 빔 서치를 비교한다 |
| **10** | MNIST 오토인코더 | 7-3 | 입력 이미지를 잠재 벡터로 압축했다가 복원하는 자기 지도 학습 모델 |
| **10a** | MNIST 오토인코더를 재활용해 만든 숫자 분류기 | 7-4 | 모델 10이 학습한 인코더 파라미터를 재활용하는 전이 학습 모델. 특징 추출 방식과 미세 조정 방식을 비교한다 |

## 3부 딥러닝을 위한 전략

| 모델 | 이름 | 절 | 그 절에서 다루는 내용 |
|---|---|---|---|
| **11** | 흉부 X선 사진 판독기 | 8-4 | 사전 학습된 ResNet-50을 흉부 X선 이미지로 추가 학습해 정상과 비정상을 분류한다 |
| **12** | 날짜 형식 변환기 모델 | 9-1 | 여러 형식의 영문 날짜 문자열을 `YYYY-M-D` 형식으로 바꾼다. 인코더-디코더 Seq2Seq 구조를 LSTM으로 구현하고 교사 강제를 적용한다 |
| | | 9-2 | 길이가 다른 입력을 미니배치로 묶어 학습한다. 패딩, 패킹, 언패킹과 `<pad>` 손실 제외를 적용한다 |
| | | 9-3 | 바다나우 어텐션을 더해, 노이즈가 섞인 입력에서도 의미 있는 토큰에 집중하게 만든다 |
| | | 10-1 | 같은 문제를 `nn.Transformer`로 다시 만들어 순환 신경망 기반 모델과 비교한다 |
| **13** | 날짜 형식 분류기 모델 | 10-2 | 노이즈가 섞인 문자열 안의 날짜가 어떤 형식인지 분류한다. 인코더만 사용하는 트랜스포머와 `[CLS]` 토큰을 사용한다 |
| **14** | 의류 이미지 생성 모델 | 11-1 | Fashion-MNIST를 학습해 의류 이미지를 생성한다. 변분 오토인코더(VAE)로 구현하며 재매개변수화 트릭과 KL 발산을 다룬다 |
| | | 11-2 | 같은 모델을 DCGAN으로 구현한다. 생성자와 판별자를 번갈아 학습한다 |

## 4부 거대한 모델의 시대

| 모델 | 이름 | 절 | 그 절에서 다루는 내용 |
|---|---|---|---|
| **15** | 뉴스 요약기 모델 | 12-2 | 사전 학습된 KoBART를 네이버 뉴스 요약 데이터셋으로 미세 조정한다 |
| **16** | 진실한 인공지능 대화 서비스 | 12-4 | 외부 문서를 검색해 근거로 삼는 RAG 시스템. 임베딩 기반 검색과 외부 LLM API 호출을 엮는다 |
| **17** | 이미지 설명 생성기 모델 | 13-1 | 사전 학습된 CLIP과 GPT-2를 고정하고 그 사이의 프로젝션 계층만 학습해, 이미지를 설명하는 영어 문장을 생성한다 |

## 여러 절에 걸친 모델

같은 문제를 다른 구조로 다시 만들어 보는 모델이다. 앞 절의 구현과 견주어 읽으면 구조를 바꿀 때 무엇이 달라지는지 드러난다.

| 모델 | 절 | 구현 방식의 변화 |
|---|---|---|
| **2** AND 게이트 시뮬레이터 | 2-2 → 2-3 | 직접 구현 → 파이토치 고수준 API |
| **4** 회오리 데이터 분류 | 3-3 → 4-2 | 직접 학습 루프 → `Dataset`·`DataLoader` 파이프라인 |
| **5** MNIST 숫자 분류기 | 4-3 → 5-2 | 다층 퍼셉트론 → 합성곱 신경망 |
| **9** 오즈의 소설가 | 7-2 → 10-3 | 임베딩 + LSTM → 디코더만 사용하는 트랜스포머 |
| **10** MNIST 오토인코더 | 7-3 → 7-4 | 오토인코더 → 인코더를 재활용한 전이 학습(모델 10a) |
| **12** 날짜 형식 변환기 | 9-1 → 9-2 → 9-3 → 10-1 | Seq2Seq → 미니배치 학습 → 어텐션 → 트랜스포머 |
| **14** 의류 이미지 생성 | 11-1 → 11-2 | 변분 오토인코더 → DCGAN |
