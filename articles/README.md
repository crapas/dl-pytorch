# 심화 학습과 추가 학습 자료 (articles)

<멀티모달까지 직접 구현하는 딥러닝 with 파이토치> 본문에서 사정상 다루지 못한 여러 주제에 대한 자료를 제공한다. 크게 추가 학습 자료와 심화 학습 자료로 구분되며, 심화 학습 자료는 연습 문제와 함께 제공된다. 

현재 준비된 내용은 다음과 같다.

## 심화 학습 자료

- 본문이 다룬 주제를 한 걸음 더 파고든다.

| 글 | 내용 |
|---|---|
| [파이토치 훅](pytorch-hook/) | - 파이토치 모델의 내부에 해당하는 각 계층의 입출력 텐서의 값과 기울기를 들여다보거나 수정하는 도구인 파이토치 훅의 사용법을 설명한다.<br>- 파이토치 모델의 기본 디버거이므로 문제가 발생했을 때 도움이 된다.<br>- 8-2절, 8-3절과 연결된 내용이므로 8-2절을 학습한 뒤에 살펴보기를 권장한다. |
| [스타일 전이](style-transfer/) | - 모델이 아니라 이미지의 픽셀을 최적화해 사진에 화풍을 입히는 스타일 전이에 대해서 설명한다.<br>- 11장의 VAE와 DCGAN과 다른 관점으로 접근하는 이미지 생성 전략이므로, 11장을 학습한 후 살펴보면 좋다. |
| [QLoRA](qlora/) | - 12-3절은 모델을 양자화해 불러오고 사용하는 방법을 다룬다.<br>- 이 자료는 여기서 한 발 더 나아가 양자화한 모델을 LoRA 방식으로 미세 조정하는 방법을 다룬다.<br>- LoRA와 QLoRA에 관심이 있다면, 이를 위한 기초 과정에 해당하므로 12-3절 학습 후에 살펴보자. |
