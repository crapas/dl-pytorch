# 심화 학습 자료 (articles)

본문에 싣기에는 분량이 크거나, 모델을 만드는 흐름에서 한 걸음 비껴 있지만 알아 두면 쓸모가 큰 주제를 따로 정리한 글 모음이다. 각 글은 **설명 자료 + 연습 문제 + 실행 가능한 예제 노트북**으로 이루어진다.

본문을 읽다가 [심화 학습] 상자를 만나면 여기에서 이어 읽으면 된다.

| 글 | 관련 절 | 내용 |
|---|---|---|
| [파이토치 훅](pytorch-hook/) | 8-2절 | 모델을 고치지 않고 계층의 입출력과 기울기를 들여다보고 바꾸는 방법 |
| [스타일 전이](style-transfer/) | 11-2절 | 모델이 아니라 이미지의 픽셀을 최적화해 사진에 화풍을 입히는 방법 *(작성 중)* |
| [QLoRA](qlora/) | 12-3절 | 양자화한 모델 위에 LoRA 어댑터만 학습해 작은 가속기에서 미세 조정하는 방법 *(작성 중)* |

## 실행 환경

예제 노트북은 저장소 전체를 내려받은 상태에서 각 글의 디렉터리 안에서 실행하는 것을 전제로 한다. 공통 라이브러리(`code_reference`)를 사용하므로, 저장소를 통째로 clone하지 않았다면 `code_reference/README.md`를 먼저 확인하자.

```
articles/<글 이름>/  ← 노트북을 여기서 실행한다
```
